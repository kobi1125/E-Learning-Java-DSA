# 📘 E-Learning App for Java & DSA

A mobile application built with **Java** and **Android Studio** to help students learn **Java programming** and **Data Structures & Algorithms (DSA)** effectively through structured modules, interactive quizzes, progress tracking, and certification.

---

## 🎯 Features

✅ User Authentication (Firebase)  
✅ Module-based Learning  
✅ Interactive Quizzes  
✅ Progress Tracking  
✅ Certification (Auto-generated PDF)  
✅ Lottie animations for beautiful UI feedback

---

## 🛠️ Tech Stack

| Layer        | Technology                            |
|--------------|----------------------------------------|
| Frontend     | Java, XML, Android Studio              |
| Backend      | Firebase Authentication, Firestore     |
| Animations   | Lottie                                 |
| Storage      | Internal File Storage (PDF download)   |
| Version Ctrl | Git & GitHub                           |

## 🧠 Why These Technologies?

- **Java**: Easy to learn, perfect for Android dev
- **Firebase**: Handles backend (auth, database) securely and fast
- **Lottie**: Adds beautiful animations effortlessly
- **Firestore**: NoSQL DB perfect for storing progress & certificates
- **Internal Storage**: Allows user to download certificate locally

---

## 📜 Certificate Example

Certificates are auto-generated in PDF and saved to the device.

## 🚀 How to Run

1. Clone the repo
2. Open in Android Studio
3. Connect Firebase
4. Run on emulator or physical device
